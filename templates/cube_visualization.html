CUBE Components Architecture
🔢 LCIC (Logical Counter Index Chain)

Maintains counter values for each keyword token. Supports forward privacy by preventing linking of updates to previous search operations.

Entries: {{ cube_stats.get('lcic_entries', 0) }}
🎯 HKI (Horizontal Keyword Index)

Maps encrypted keyword tokens to sets of document IDs. Enables efficient search without decrypting documents.

Entries: {{ cube_stats.get('hki_entries', 0) }}
⛓️ VKIC (Vertical Keyword Index Chain)

Maintains version chains for keyword-document pairs. Supports backward privacy by ensuring deleted documents cannot be recovered through stale index states.

Entries: {{ cube_stats.get('vkic_entries', 0) }}
📑 DIC (Document Index Chain)

Tracks which documents have been indexed with which keywords. Used for managing dynamic insertion and deletion operations.

Entries: {{ cube_stats.get('dic_entries', 0) }}
